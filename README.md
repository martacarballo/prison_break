GAME NARRATIVE

You are in your jail cell and have a possibility of escaping from there.

You have to follow a path throughout the different jail rooms, trying to open each one using the objects you can find in it.

Each room function will describe the room, show the objects, and ask the player to choose one.

When choosing a key, the player will be able to move to the next room or escape in case you are in the last room.

If the player chooses an object that is not a key, they will be prompted to choose again and show an object description
